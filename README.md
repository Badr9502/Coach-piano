# Coach Piano

Prototype d'application de pratique du piano :
- doigtés suggérés (main droite / gauche),
- tempo de départ conseillé selon la difficulté et le niveau,
- lecture d'une photo ou capture d'écran de partition, directement dans le navigateur (`omr.js`, sans serveur),
- métronome qui écoute ce que tu joues (micro) et conseille de monter, rester ou descendre le tempo.

Ouvre `index.html` via GitHub Pages (https) pour que le micro fonctionne, y compris sur cellulaire.
